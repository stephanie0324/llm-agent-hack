# Getting Started


To deploy the application simply go to `deploy` folder.  
1. Modify `.env` file
    * OPENAI_API_KEY
    * HOST_PORT
    
2. Build image
```
bash script/build-docker-image.sh
```
3. Start the application
```
docker-compose up -d
```
